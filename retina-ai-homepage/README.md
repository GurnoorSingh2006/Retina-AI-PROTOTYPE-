# 👁️ RetinaAI — Standalone Cinematic Showcase Experience

An immersive, scroll-synchronized interactive digital art experience designed around **Retina AI**.

---

## ⚡ Highlights
- **Scroll-Driven Video Scrubbing**: Interactive frame-by-frame scrubbing through the cinematic high-resolution eye video synced to viewport scroll progression.
- **Narrative Progression**: 8 seamless cinematic scenes transitioning from darkness into cellular layers, pathology detection, and diagnostic resolution.
- **Ultra-Clean Frosted Glass Aesthetic**: Pure void-black background (`#050505`), translucent glass cards (`backdrop-blur-sm bg-black/25`), and luminous retinal red accents (`#8F1515`, `#E0533C`).
- **1-Click Deployment**: Zero complex backend dependencies — can be deployed standalone to **Vercel** or **Netlify** in under 60 seconds.

---

## 🛠️ Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS + Lucide React
- **Asset**: `public/videos/eyenew.mp4`

---

## 🚀 How to Run Locally

### 1. Install Dependencies
```powershell
npm install
```

### 2. Run Development Server
```powershell
npm run dev
```
*Open `http://localhost:3000` in your browser.*
